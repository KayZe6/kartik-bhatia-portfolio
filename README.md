# Portfolio

Personal engineering portfolio for Kartik Bhatia, an aerospace engineering student at the University of Maryland. Showcases case studies, projects, skills, and outreach work.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

## Project structure

All page content (case studies, projects, skills, outreach, contact info) lives in `data/` as typed data files. Components read from these files rather than hardcoding copy.

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Other scripts:

```bash
npm run build   # production build
npm run start   # serve the production build
npm run lint    # eslint
```
